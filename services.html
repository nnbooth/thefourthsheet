The question everyone asks

“Can I have it in Excel?” Yes.

In the data world that question usually gets an eye-roll. Not here. I'm technology agnostic: if your team lives in Excel, the report lands in Excel. The tool should fit the business, not the other way around.

  • Excel, done properly. A workbook that updates itself from the source, with the same numbers as any dashboard, so nobody copies and pastes at month-end.
  • Use what you've already got. Already paying for Power BI, Salesforce or your ERP's reporting? I build on it rather than asking you to replace it.
  • New tools only if they earn it. If a new licence would genuinely save you time or money, I'll show you why. If it wouldn't, you won't hear about it.
